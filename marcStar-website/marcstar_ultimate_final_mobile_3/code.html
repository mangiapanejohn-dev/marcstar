安装 MarcStar

您的下一代个人智能终端。遵循以下三个简单步骤完成部署。

最新版本 (v2.1.0)

适用于 macOS 12.0 或更高版本 (Apple Silicon & Intel)

安装指南

1

download 下载

点击上方的下载按钮获取最新的 .dmg 安装包。下载完成后，双击打开该文件。

2

drag_indicator 移动

在打开的窗口中，将 MarcStar 图标拖拽到 Applications (应用程序) 文件夹快捷方式上。

3

admin_panel_settings 授权

首次打开时，系统可能会提示应用来自互联网。前往系统设置 > 隐私与安全性，点击"仍要打开"。

系统要求

组件 最低要求 推荐配置
操作系统 macOS 12.0 (Monterey) macOS 14.0 (Sonoma)
处理器 Intel Core i5 / Apple M1 Apple M2 或更高
内存 (RAM) 8 GB 16 GB 或更高
