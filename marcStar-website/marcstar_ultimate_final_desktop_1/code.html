Architecture Overview

MarcStar 采用混合架构，旨在提供原生 macOS 体验的同时保持高度的灵活性。我们结合了现代 Apple 框架与成熟的 Web 技术栈。

integration_instructions

SwiftUI 层

作为主应用的入口和基础 UI 框架，负责窗口管理、菜单栏集成以及核心偏好设置界面的渲染。

public

WebKit 核心

利用高性能 WKWebView 承载复杂的 Markdown 渲染和动态 AI 交互面板，确保跨平台逻辑一致性。

memory

AppKit 深度集成

在需要底层系统访问时（如全局快捷键注册、深色模式强制覆盖或特定的沙盒机制穿透），通过桥接模式调用原生 AppKit API，弥补 SwiftUI 的功能边界。

贡献指南

Contributing Guide

call_split Fork & Branch (分支管理)

请在克隆项目后，从 main 分支创建您的特性分支。分支命名规范建议：feat/your-feature 或 fix/issue-number。

git checkout -b feat/add-new-shortcut

code Code Style (代码风格)

Swift 代码请遵循 SwiftLint 标准，Web 前端代码（Tailwind/TS）请运行我们提供的 Prettier 脚本进行格式化。

merge Pull Request (提交请求)

提交 PR 之前，请确保所有本地测试通过。在 PR 描述中清晰说明您的改动目的，并关联相关的 Issue。我们将在一周内进行 Code Review。
